# meetomnia-site-original

Pristine backup of the original Webflow-exported meetomnia.com site, saved on 2026-09-23 before the lead-generation copy rewrite.

- `meetomnia-export.zip` — the complete original site: `index.html` plus the `assets/` folder (stylesheets, scripts, images, favicon). Unzip to restore.

This repo is a backup only. It is not connected to Cloudflare Pages and nothing here is deployed.
The live site is built from salimmohammed/meetomnia-site.
